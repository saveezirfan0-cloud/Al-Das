# Next-phase prompts for Claude Code

Companion to `docs/09_STATUS_AND_ROADMAP.md` (read it first; it explains why each phase exists and what you must supply). Same method as `docs/02`: **open a fresh Claude Code session per phase, press Shift+Tab for Plan Mode, paste the prompt, review the plan, then let it build.** `CLAUDE.md` rules apply to every phase and are not repeated except where a phase makes them bite.

Phase 12a (UX foundation) is already done. Start at 12b.

## Paste this at the start of every session

> "Read CLAUDE.md, docs/09_STATUS_AND_ROADMAP.md and the phase notes for the area you will touch. Work in Plan Mode first. Show me the plan, the files you will touch, the migrations, the tests, and any question you need answered. Do not call any external service (Meta, Unite, Anthropic, Resend) from tests. Stay on the branch I name. When done, run `pnpm typecheck && pnpm lint && pnpm test` (and `pnpm test:db` if you changed SQL), update the docs that describe changed behaviour, and write `docs/NN_PHASE_X_NOTES.md` with: what exists, how it was verified, what was NOT verified, and open questions."

## Definition of done for every phase (copy into the prompt if you like)

Typecheck, lint, unit and DB tests pass. New tables have RLS and an `org_id` policy (or an entry in the service-only list in `tests/db/security-guard.test.ts`). New server actions and routes call `requirePerm`/`can` and, if they mutate, `recordAudit` (or a reasoned entry in `lib/security/policy.ts`). Nothing logs tokens, full phone numbers or message bodies. No real patient data anywhere. Anything unauthenticated is rate limited. The happy path was clicked in a browser on a real stack, and the notes say so.
